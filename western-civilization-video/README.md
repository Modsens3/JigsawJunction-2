# Η Ιστορία του Δυτικού Πολιτισμού – animation βίντεο (~3 λεπτά)

Το έτοιμο βίντεο είναι το αρχείο **`western_civilization.mp4`** (1280x720, 30 καρέ/δευτ., με μουσική).
Απλώς κατέβασέ το και άνοιξέ το με οποιοδήποτε πρόγραμμα βίντεο.

Στο κάτω μέρος υπάρχει **χρονογραμμή** που δείχνει σε ποια εποχή βρισκόμαστε.

## Πώς ξαναφτιάχνω το βίντεο (αν αλλάξω κάτι)

Χρειάζεσαι Python 3. Άνοιξε ένα τερματικό μέσα σε αυτόν τον φάκελο και γράψε:

```bash
pip install pillow numpy imageio-ffmpeg
python3 make_video.py
```

Σε λίγα λεπτά δημιουργείται ξανά το `western_civilization.mp4`.

### Εύκολες αλλαγές
- **Κείμενα / λεζάντες / εφευρέσεις:** στο αρχείο `make_video.py`, στη λίστα `SCENES`.
- **Διάρκεια σκηνών:** στο `make_video.py`, οι τιμές `TITLE_T`, `SCENE_T`, `EPI_T` (σε δευτερόλεπτα).
- **Σχέδια μνημείων:** στο `scenes.py`. **Σχέδια εφευρέσεων:** στο `icons.py`.
- **Μουσική:** στο `music.py` (συντίθεται αυτόματα, δεν χρειάζεται αρχείο ήχου).

Για γρήγορο έλεγχο χωρίς να φτιαχτεί όλο το βίντεο:
```bash
python3 make_video.py --stills stigmiotypa
```
(αποθηκεύει εικόνες από κάθε σκηνή στον φάκελο `stigmiotypa`).
